# 能力依存の定数の再評価の記録

能力依存の定数(`scripts/gate/recalibration-registry.json`。標準 第3章 3.12.12「能力依存の定数の登録簿」)を、**人が**「残す・外す・移す」と判断した記録です。`/process-change` の出力と `/pit` が出す「再評価待ち」は、ここに記録があると解けます。

- 値は自動で変えません。値を変えるときは `/process-change`(種別 settings)を使います
- 記名は名簿(`people[]`)の人に限ります。AI の名義の行は数えません
- 「外す」場合と「移す」場合は、「移した先の保証」を書きます(定数を外しても、担っていた保証を失わないため)。「外す」で移した先が空の行は、再評価の記録として数えません
- 契機は、`/process-change`(種別 performer)の記録にあるモデル・指示資産の版の変更と、半期の暦だけです。能力に依らない周期・窓(RC-09〜RC-12)は、再評価待ちに数えません
- RC-07 の分量の上限(組織が定める値。参考の値は 200行)は、構成(`process.config.json`)ではなく `.claude/guard.json` の `instructionAssetLimit.maxLinesPerFile` に置きます。6,000 トークンはテンプレートの CLAUDE.md の目標で、合否に使いません。どちらも構成のキーを持たないため、登録簿の `configKey` は null です
