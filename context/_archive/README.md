# 保管領域

役目を終えた文脈ファイルの置き場です。

**このディレクトリはエージェントの参照対象から明示的に外します**。削除ではなく退避にするのは、後から経緯をたどれるようにするためです。

参照対象に残したまま「古い」と注記する方式は採りません。注記は読まれず、古い記述がそのまま使われます。

## 移すもの

- 終了した案件の案件層ファイル
- 置き換えられた設計標準
- 使われなくなった用語(用語集からは削除し、ここへ経緯を残す)
- 全部を置き換えた判断記録(ADR)と、廃止した判断記録。状態を「置き換え(→ ADR-MMM)」または「廃止」にした変更で、`decisions/` へ移す(`context/_archive/decisions/NNNN-*.md`)

## 移さないもの

- 一部を置き換えた判断記録(状態「一部置き換え(→ ADR-MMM の決定 n)」)。効いている決定を含むため、`../decisions/` に残す

判断記録を移す契機は、状態だけです。移動は、置き換える判断記録(または廃止)を判定した G-3 の帰結の事務であり、読み込み実績に基づいて外す判断(AI維持管理者の棚卸し)ではありません。保管の記録(外した日・理由・外した者・復帰の条件)は、状態の行(日付と、置き換え・廃止)、その G-3 の判定記録(判定者)、「置き換えた判断記録が廃止されたとき」(復帰の条件)で満たします。移した判断記録を削除しません。状態と置き場の一致は `node scripts/gate/check-decisions.mjs` が検査します(標準 第6章 テンプレ2「置き換えと廃止」)。

このディレクトリの読み込みは、`.claude/settings.json` の `permissions.deny`(`Read(./context/_archive/**)`)で拒否しています(標準 第3章 3.11.4 要求事項7)。
