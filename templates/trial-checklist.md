# 試行前チェックリスト(T-1 開始条件)

`docs/trial-checklist.md` として置きます。標準 第8章「社会実装の段階の調整」の試行前チェックリストの写しです。標準の様式番号を持ちません。T-1 の限定試行は体制の人数によらず実施します(1〜2名の体制では、対象そのものが試行になります)。

**全項目を確認してから、試行を始めます**。未充足の項目がある状態で、試行を始めてはなりません。とくに、撤退の条件を定めない試行を始めてはなりません。中止できない試行は、成果の有無にかかわらず継続され、判断の材料にならないためです。

- 確認した項目は `- [x]` にします
- 体制に該当しない項目は、チェックを付けず、行末に「該当なし: <理由>」と書きます。**理由の無い「該当なし」を、確認済みとして扱いません**。空欄のまま開始しません
- 検査は `node scripts/gate/trial-checklist.mjs` です。チェックの無い行、理由の無い「該当なし」、免除の期限の無いサンドボックスの行、延長の決定の無いまま期限を過ぎた免除を出します。`/pit` も同じものを注記に出します。**機械が見るのは形だけです**。項目が実際に満たされているか、試行を始めた時点は、試行の責任者が確かめます

## 試行前チェックリスト(T-1 開始条件)

<!-- 体制に該当しない項目は、チェックを付けず、行末に「該当なし: <理由>」と書く。空欄のまま開始しない -->

### 体制
- [ ] 試行の責任者が1名特定されている(役割として。個人名は D-0 の表5 に隔離する)
- [ ] 参加者の稼働時間が公式に確保されている(見込み工数と確保時間を数値で記載)
- [ ] 支援担当(EN-1)が割り当てられ、関与の期間が定められている
- [ ] 支援担当は、適合性を判定する組織に属していない

### 前提条件
- [ ] T-0 の7項目を評価し、未充足項目の是正が完了または計画済みである
- [ ] 対象範囲(対象・環境・変更種別・リスク区分)が文書で確定している
- [ ] リスク区分 R1 を含む場合、AI自律レベルが L1 に固定されている
- [ ] 適用条件に該当する場合、安全リスクアセスメントが承認されている
- [ ] 既存規程の免除を要する場合、サンドボックス申請が承認され、免除の期限が記録されている

### 測定
- [ ] 開始前の実測値を取得済みである(下記の指標を対で取得)
- [ ] 測定の期間と母数の下限が定められている
- [ ] 自己申告による生産性の変化を、成果指標として用いない旨が合意されている

### 差し引き
- [ ] 廃止または置換する既存の承認・様式が特定されている
- [ ] 導入後の判定件数が、置換前を上回らないことを確認した

### 撤退
- [ ] 中止の条件が事前に定められている
- [ ] 中止した場合に元の手順へ戻す方法が定められている

## サンドボックスによる免除(適用: 既存の品質マネジメント規程または決裁権限規程を持つ組織で、その条項の手続を期限を定めて免除する場合)

規程を持たない体制では、この節を書きません。上の「既存規程の免除を要する場合」の行を「該当なし: 既存の規程を持たない」とします。

| 免除する既存規程の条項 | 免除の期限(YYYY-MM-DD) | 承認の記録の所在 | 延長の決定(新しい期限と決定の記録の所在) |
| --- | --- | --- | --- |
| | | | |

- **サンドボックスは、本標準の要求事項を免除しません**。附属書H H.3 の内部監査も免除されません。免除するのは、既存規程の条項の手続だけです
- **期限は自動では延びません**。期限を過ぎた免除は、延長の決定が無ければ失効しています
- 延長は、新しい期限を記録した決定です。**元の期限の欄を書き換えません**。「延長の決定」の欄に、新しい期限(YYYY-MM-DD)と決定の記録の所在を書き足します。延長を重ねるときは、同じ欄に「; 」で区切って足します
- 申請の様式・承認者・手続は、採用組織が定めます(標準は定めません)。承認の記録の所在だけを書きます
