## 事業への影響

金額での定量化は義務ではありません。書く場合は3点を併記します。

| 項目 | 内容 |
| --- | --- |
| 影響を受ける利用者・業務 | この選択が裏目に出たとき、誰の何が止まるか |
| 顕在化が分かる兆候 | 何を観測すれば誤りだったと分かるか。**「なし」と書かないこと** |
| 回復に要する時間 | **幅で書く。単一の値は不可** |
| 取り消しの可否 | 自動で戻せる / 人手で戻せる / **相手方の同意を要する**(この場合は R1) |
| 影響する必達基準 | 項目番号 / 該当なし |
| (任意)金額 | 算定根拠 / 過去案件 / その額にならない条件 の3点を併記 |

**発生確率と影響度の格付けを掛け合わせた順位づけを書かないでください**。掛け合わせた値は、桁の異なる2つの見積りを1つの数字へ潰します。
