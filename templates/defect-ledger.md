# 欠陥の台帳

`docs/defect-ledger.md` として置きます。出荷判定(G-7)の基準2(未解決の欠陥)の入力です(標準 第4章 G-7「基準1・2 の記録」)。標準の様式番号を持ちません。欠陥管理の道具(Issue の追跡など)を使う組織は、出荷の前にこの形へ書き出します。

**台帳が無い出荷は、基準2 を確かめられないため記載の欠落**になります。既知の欠陥が無い場合も、表を空にして「既知の欠陥なし」と書いた台帳を置きます。

## 台帳

| ID | 現象 | 重大度(Sev1 / Sev2 / Sev3) | 優先度 | 状態(未解決 / 解決済み) | コア機能(はい / いいえ) | 回避策(文書の所在) |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

- 重大度は技術側が観測可能な事実で決める(Sev1: 停止・データの破損・認証認可の破れで回避策が無い / Sev2: 文書化した回避策がある / Sev3: 業務は継続できる)。優先度は事業側が決める
- 出荷判定の証跡の集約が、事業ステージ別の欠陥トリアージ基準の区分ごとに未解決の件数を出す(S1 の Sev1 はコア機能とそれ以外に分けて数える)。**出荷の可否を機械は判定しない**。出荷判定者が基準と突合する
- 回避策は文書化されていなければ存在しないものとして扱う
