# 次の一手を出す

プロセスの全体を覚えておく必要はありません。次の一手は、状態から機械が出します。

## 手順

### 1. 状態を出す

```bash
node scripts/gate/next.mjs
```

自分のロールが分かっている場合は、ロールを指定します。ロールの判定するゲート・判定してはならないゲート・受信箱のコマンド・引き渡しのラベルも出ます。

```bash
node scripts/gate/next.mjs --role <ロール>
```

### 2. 出力に従う

| 出力 | すること |
| --- | --- |
| `[次のコマンド]` | そのコマンド(スキル)を実行する。「読む:」の行があれば、そのファイルを読んでから実行する |
| `[人の判断待ち]` | **終端です**。コマンドを実行しない。待つ席の受信箱のラベルを付けて渡し、利用者へ「誰の何の判断を待っているか」を伝える |
| `[判定できない]` | 推測で進めない。理由を利用者へ伝え、人に状態を確かめてもらう |
| `[完了]` | その機能について、することはない |

機能が複数ある場合は、機能ごとに一手が出ます。1つにまとめないでください。

### 3. 利用者へ示す

出力のうち、利用者に関係する行をそのまま示します。言い換えて要約しないでください。

## このスキルがしないこと

- 状態を推測で補うこと。出力に無い一手を足すこと
- 人の判断待ちを飛ばして、次の段階のコマンドを実行すること
- PR・ラベル・CI の状態の判定(`next.mjs` はローカルの git だけを見ます。見ていないものは出力の末尾に出ます)
