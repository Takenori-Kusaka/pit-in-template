# ゲート判定を記録する

ゲートごとの知識は補助ファイルにあります。**指定されたゲートの1枚だけを読みます**。

## 判定の原則(全ゲート共通)

1. **記録をもって判定が成立する**。判定記録を作成し、リポジトリへコミットした時点で成立する。Issue・PR・ラベルの操作は事務であり、記録の無い期間は未判定
2. **判定は人が行う。このスキルが行うのは、材料と記録の様式を整えることだけ**。結果の欄を先に埋めない。判定者・確定の形態・異議・受容の記名を AI が書かない
3. **判定に持ち込むのは、当該ゲートの判定基準と全ゲート共通の通過条件だけ**。次工程の材料の未完成、基準に無い懸念、投資を続けるか(SG で扱う)を持ち込まない
4. 全ゲート共通の通過条件: 当該の工程に関係する前提の充足状態が前提の台帳(`docs/assumptions.md`)に記録され、AC-1 以上に受容の決裁があること。前提の定義と観測の手がかりの要約は `.claude/skills/artifact/artifacts/10-assumption-ledger.md`(外部のサイトを読まずに記入できる)。台帳が無ければ、判定の材料を揃える前に作る
5. 判定は「通過 / 差し戻し」の2値。**条件付き通過は無い**。基準を満たさないまま進めるのは例外承認だけ(`reference/exception-paths.md`)

## 手順

### 1. ゲートを決め、補助ファイルを読む

`node scripts/gate/next.mjs` の出力に「読む:」があれば、その1枚を読みます。無ければ、利用者が指定したゲートを使います。

| ゲート | 補助ファイル | 判定者の席 |
| --- | --- | --- |
| G-1 企画承認 | `gates/G-1.md` | 事業決裁者 |
| G-2 要件合意 | `gates/G-2.md` | 価値責任者 |
| G-3 技術設計判断 | `gates/G-3.md` | 技術判断者 |
| G-4 機能仕様承認 | `gates/G-4.md` | 価値責任者(または委譲先) |
| G-5 自動検証(CI) | `gates/G-5.md` | 機械(人の判定記録は作らない) |
| G-6 独立レビュー | `gates/G-6.md` | 独立レビュア |
| G-7 出荷判定 | `gates/G-7.md` | 出荷判定者 |
| G-8 リリース決裁 | `gates/G-8.md` | 事業決裁者 |
| SG ステージ移行 | `gates/SG.md` | ステアリングコミッティ(会議体) |

所在は、このスキルのディレクトリ(`.claude/skills/gate/`)からの相対です。判定者の席の責任者は `node scripts/gate/next.mjs --role <ロール>` で確かめます。

### 2. ゲートが有効かを確かめる

```bash
node -e "const c=require('./process.config.json');for(const[k,g]of Object.entries(c.gates))console.log(k,g.state,g.label)"
```

`required` または `simplified` のゲートだけ記録を作ります。省略したゲートの記録は作りません。未達のゲートは、未達のまま表示されます。

### 3. 様式から起こす

```bash
cp templates/04-gate-record.md docs/gates/<ゲート>-<対象>-<日付>.md   # 例: docs/gates/g4-F-012-2026-08-08.md
```

### 4. 材料を集めて、突合の表を起こす

補助ファイルの「材料の集め方」に従います。共通の欄(確定の形態、参照した D-0 の版、リスク区分、判定基準の表の展開)の書き方は `reference/recording.md` にあります。

- 機械で確かめられる基準は、機械が確かめた範囲を書く(「空欄でないことだけを見た」など)
- 人の判断が要る基準は、**材料だけを書き、結論を書かない**

### 5. 判定者へ渡す

判定者(人)が判定し、結果・差し戻し理由・記名を書きます。差し戻しの理由は、**判定基準の項目番号**で書きます(「もう少し検討してください」は理由にならない)。

### 6. 記録を書いてからラベルを動かす

順序は「判定基準との突合 → **記録の作成** → `state:*` ラベルの遷移 → Issue・PR の事務」です。逆にしません。記録の無いまま次工程へ渡っている状態を見つけたら、着手せず判定者へ差し戻します。

### 7. 次の一手を示す

```bash
node scripts/gate/next.mjs
```

「人の判断待ち」が出たら、コマンドを実行せず、待つ席へ受信箱のラベルで渡します。

## 期限を超えたとき

判定の期限(G-2・G-3 は48時間、G-4 は24時間、G-6 は2営業日、G-7 は3営業日が目安)を超えても、**自動承認にしません**。エスカレーションし、期限を過ぎたことも記録に残します。

## 旧名 /gate-record

`/gate-record` は、このスキルの旧名です。同じ手順で、ゲートを指定して使います。
