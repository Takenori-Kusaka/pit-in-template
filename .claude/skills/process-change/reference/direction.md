# 向きに応じて進める

`/process-change` の手順5 の詳細です。

| 向き | 扱い |
| --- | --- |
| 厳しくする向きだけ | 即時に適用する。判定を待たない |
| 未達・逸脱の発生 | **即時に適用する。記名を要求しない**。旧い構成のまま止めない。未達のまま出荷するかどうかは、標準 第7章 7.3 の例外承認による(CL1 以上と規制業は不可) |
| 緩める向きを含む | **決定した者の記名と理由を利用者から受け取り**、`decidedBy` と `reason` へ書く。受け取るまで適用しない |
| ステージを前へ戻す | **SG の判定による**。D-0 表1「体制と運用形態」の決定者の記名を要する。判定記録の所在を `sgRecord` へ書く(`kinds/axis.md`) |
| 任免の決定 | **変更前の決定者(体制から外れていれば組織上の任命権者)の記名と理由を受け取る**。受け取るまで適用しない |
| 構成の変更なし | そのまま適用する。「構成の変更なし」が記録される |

## 「発生」と「緩める向き」を見分ける

**「発生」として扱うのは、人が実際に減った場合に限ります**(名簿の体制内の人が減った、または席の責任者が名簿から外れた)。

| 変化 | 扱い |
| --- | --- |
| 人が離脱し、チーム規模の回答が下がった結果、G-7 が兼務になる、承認数が変わる | 発生。記名を要求しない |
| 人が離脱し、作成を指示する席の責任者のほかに、確認できる人が名簿に残っていない結果、G-6 が未達になる | 発生。記名を要求しない |
| 人が離脱し、空いた席を残った人が引き取る | 離脱は発生。**引き取り(後任の配置)は任免の決定であり、決定者の記名を要する**。離脱だけを先に反映してもよい |
| **誰も離脱していないのに、回答を「確認者なし」へ変える、独立レビュアの席を開発者と同じ人にする** | **緩める向きの決定**。記名と理由を要する |
| 人が離脱したが、確認できる人が名簿に残っているのに、独立レビューを置かない | 緩める向きの決定 |
| 1名の体制で、全席を同じ人が兼ねる | 兼務には選択の余地がない。逸脱として記録される。ただし全席が未記入の状態からの記入そのものは任免であり、本人の記名と理由を要する(初回の記入) |
| 2名の体制で、相手がいるのに、AI維持管理者と AI運用担当者を同じ人が兼ねる | 緩める向きの決定 |

## 無効になった確認

無効になった確認の候補を文脈オーナーへ示し、やり直しの要否を決めてもらいます。決まった内容を `invalidatedChecks` へ書きます。

```json
"invalidatedChecks": [{ "target": "PR #12 の独立レビュー", "redo": true }]
```
