# 種別 schedule-only: 納期・目的・範囲・予算だけの変更

納期・目的・範囲・予算だけが変わり、変化点の種別 1〜5(`accountable`・`headcount`・`mode`・`performer`・`axis`)へ波及しない場合です。**変化点に数えません。起票された場合は「構成の変更なし」と記録します**。

```json
{ "kind": "schedule-only", "summary": "リリースの予定日を 2026-11-15 へ移した" }
```

- **納期を理由に統制を外す要求は、`schedule-only` では扱えない**。統制を緩める向きの変更として、該当する種別で、決定した者の記名と理由をつけて反映する
- `schedule-only` で構成が変わる入力(回答・席・委任・個別の値)を渡すと、スクリプトが拒否する。拒否を回避するために種別を書き換えない
- 範囲の変更が、合意した範囲(スコープの3層)を外れる場合は、G-4 の範囲外の判定と第2章 2.10 の手続による(`.claude/skills/gate/gates/G-4.md`)。構成の変化点ではない
