# 種別 end: 適用の終了

案件への本標準の適用を終えた記録を残します(標準 第1章 1.10.4)。**変化点に数えません**。適用の終了は、この記録を残した時点です。記録が無い案件は、適用を続けているものとして扱います。

```json
{ "kind": "end", "endReason": "closed", "summary": "案件を完了した", "decidedBy": "<記名の自然人>", "reason": "<終える理由>" }
```

| `endReason` | 理由の区分 |
| --- | --- |
| `closed` | 案件の完了・中止 |
| `operation-ended` | 運用の終了 |
| `withdrawn` | 採用の取り下げ |

- 決定した者(`decidedBy`)と理由(`reason`)を要する。**AI の名義を書かない**。終了を決めるのは人である。名前と理由を推測で埋めない
- 一時停止・期日の失効・範囲の縮小の区分は無い(標準が置かないと決めた)
- `configured` は `true` のまま残す。構成を未設定へ戻す変更は、契約検査が落とす
- 終了の後は、現在形の適用の表明をしない。公開の表示は、適用していた期間を示す形へ改めるか、外す(残作業として人へ渡す)
- 終了より前の範囲の適合の主張は、判定が指す記録を保管している間だけ有効である。記録を消さない
- 終了の後は、種別 `notice` のほかの変化点を追記できない。**同じ案件で再び適用を始める記録は、準拠テンプレートにまだ無い**。再開すると、件数は最初の適用の開始から数え、終了から再開までは記録の欠落になる(標準 第1章 1.10.4)
